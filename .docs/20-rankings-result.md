## 已实现内容

| 界面 | 当前行为 | 数据边界 |
|---|---|---|
| 首页四榜 | 城市举办、会议热度、城市热度、城市期待；选择按钮、内容两侧悬浮箭头、榜单详情；无页码或播放按钮 | 举办榜真实；热度尚未开启；期待读取本机累计 |
| `#/rankings` | `board` 切榜，城市举办榜完整排名、国家、关联会议与年份；`q` 搜索，可恢复地址状态 | 搜索保留原名次，不生成假数据 |
| 城市期待 | 表达希望城市承办会议；同城每次 `+1`，可连续累计且不取消；零票仅为候选 | 仅当前浏览器，不是全站票数或独立人数 |
| 首页支持 | 默认爱心“支持一下”，连续点击累计并显示 `+1` | 本机预览无每日上限，不是全站支持总数 |
| 社交入口 | GitHub 与用户给定小红书链接新标签打开；小红书可由公共 URL 配置覆盖 | 默认地址真实，缺失或无效覆盖回退默认地址 |

本机支持和期待通过版本化浏览器存储保存、共享响应式状态，并接收其他标签的存储变化；保存失败则继续本次浏览并提示。非法或损坏存储不会使页面崩溃。期待与支持都为连续加一，没有取消或页面重置入口，可通过清除浏览器站点数据重置本机预览。多标签保存采用浏览器存储，并不提供数据库级并发精确计数承诺。

小红书默认采用用户提供的 `https://xhslink.cn/o/5YIh8OKvkvn`；`VITE_XIAOHONGSHU_URL` 可覆盖，仅接受允许的 HTTPS 小红书地址，无效或空配置回退默认链接。GitHub 指向 `https://github.com/yinwen2019/ai-travel-ddl`。公共环境变量会进入前端产物，不能用于保存仓库或云服务写密钥。

## 布局与动效事实

- 保留冷蓝灰、系统字体、开放列表和细分隔线；没有新增全局设计 token。Rankings 最大宽度 1280px，桌面列表与口径说明分栏，手机将说明移到列表前；四榜选择桌面四列、手机两列。
- 首页四榜只通过四个选择按钮与内容两侧 44×44px 悬浮箭头手动切换；按用户后续批注移除页码与播放控制，因此不设置自动播放定时器或聚焦／悬停暂停逻辑。箭头偏移避让列表，选择后不转移焦点。
- 切换淡入 220ms、退场 120ms，仅改变透明度；减少动态效果直接切换。面板有稳定最小高度，地球与简介不随榜单平移。
- 支持爱心点击反馈 280ms，`+1` 反馈 650ms，快速连点最多同时保留五个视觉粒子；减少动态效果保留计数与短文字确认，取消缩放和位移。
- 主要操作与社交图标至少 44px。城市详情新标签打开并说明去向，期待按钮独立于链接，数字和反馈具有辅助技术说明。
- 首页 Canvas 地球的并行交付保留其已有规范；本记录仅补充榜单与互动，不将该地球的变更归入本轮排行榜实现。

## 已确认口径与后续接入

[统计推进方案](./19-rankings-analytics-plan.md) 已根据 2026-10-16 用户确认更新：

1. 热度按显式主动实体点击全部累计，真实重复点击分别计数；不设停留门槛、日去重或周期，不计自动组件变化、hover、曝光、筛选、切年及轮播。
2. 集中 `click` / `auxclick` 入口与地图、表格明确用户选择调用同一统计服务；一次动作只给一个对应实体 `+1`，官网只计会议，城市链接只计城市，目标页挂载不补计。事件 ID 只对网络重试幂等。
3. 城市期待表示希望城市承办会议，可对同城反复加一、不取消；爱心支持连续加一，不设置每日 10 次等产品额度。匿名 ID 只辅助异常速率保护，不用于一人一票。
4. 后续采用 Cloudflare Worker + D1 免费方案，统计为独立互动数据域；REQ-B01 既有会议静态数据仍只读。本轮不创建云资源或部署。
5. 小红书用户地址已经提供并作为默认，公共配置可覆盖。

产品规则与免费架构方向已确认，实际服务仍未创建或接入，全站统计保持未开启。本机预览不自动上传或迁移成全站数据；云账户、域名和上线细节在后续服务实施阶段处理。
