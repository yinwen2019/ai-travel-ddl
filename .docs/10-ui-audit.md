# 10 — UI 现状审阅与文档校对

审阅日期：2026-10-14。范围：三个主视图、共享导航、卡片与持续更新展示逻辑。基于本地源码和浏览器桌面/窄屏查看，含年份页深色检查；不代表所有交互、设备和异常路径均已验收。本次只修改 Markdown，不修改需求范围、页面代码或数据。

## 界面氛围

整体为白底/深蓝灰底、绿色指南针品牌、细边框圆角卡片的小型信息工具。正文大量使用 12px 字号，会议全称在列头为 11px；历史卡片整体透明度 0.6，层级较弱。渐变地点链接、列头彩线和 Traveling 标记带旅行气息，但视觉重点仍以资料列表为主。分类色、DDL 状态色和装饰渐变同时出现，语义需要更清楚。页脚仍写 AI Top Conf，与顶栏 AI Travel DDL 不一致。

## 三个视图的实际展示逻辑

| 视图 | 当前实现 | 使用体验与边界 |
|---|---|---|
| 会议 `#/` | 顶部五分类复选矩阵；一会议一列，按源数据会议顺序排列；有效 upcoming 年份降序，其后历史默认两届，可展开 | 适合追踪某会议跨届变化；桌面固定 260px 横向滚动，移动最小宽度 86vw；非文档所述自适应列宽 |
| 年份 `#/year` | 顶部年份 Tabs，来自全部数据并降序，默认浏览器当前年份；仅展示该年份有条目的会议 | 最早未截止 DDL 优先，其次无未来 DDL 的未结束会议，最后历史/已结束；同档按名称排序；当前窄屏四列挤压 |
| 世界 `#/world` | 本地 GeoJSON + Leaflet 城市聚合点，上地图下年表；年份降序、会议按分类及名称排序 | 分类只过滤表格，地图始终全量；表格 hover 高亮城市、列头点击定位会议城市；城市点击固定 Tooltip。顶栏搜索仍显示但不影响世界数据 |

共享状态：搜索、多选、年份、世界分类在模块内共享，切换路由保留；没有为这些筛选提供持久化。会议页无选择时用搜索结果，有选择时直接用已选会议，因此搜索与多选未取交集，空状态却仍按搜索结果判断。年份页不使用会议多选。

## 卡片与日期状态

- 会议列与年份网格共用 ConferenceCard，均显示开会日期、地点、官网和可用进度节点；卡片不显示会议全称（全称位于会议列头）。卡片标题未链接会议详情，详情路由已存在。
- history 或 end_date 早于 UTC 今天：已结束、灰色降透明；end_date 当日仍视为未结束。
- 尚未结束：合并摘要/正文 DDL，取最早未截止日期；不按 notification/camera_ready 排序。
- 有投稿 DDL、均已截止且有未来开会日期时进入 Travel；正在开会显示 Traveling!，隐藏进度条。Travel 状态保留地点和官网，旧需求中“隐藏举办地”与实现不符。
- 无有效 DDL 不等于可投稿：当前色条默认绿色，日期全缺时显示“日期待公布”。这是状态表达歧义，重构时需明确未知信息的视觉语义，不能补造日期。
- ProgressBar 实际仅包含数组第一条摘要、第一条正文与开会日期，缺失跳过；无“现在”和“结束”节点，无移动端两节点简化，过期文案只有“已截止”。它与卡片取全部 DDL 中最早未截止日期的规则可能不同。
- 日期按 UTC 零点计算，未使用 entry.timezone 换算精确截稿时间；不应向用户暗示小时级精度。

## 持续更新网站的边界

数据为构建时 JSON import，浏览器不实时查询 AI/API。新数据要经更新、审核合并和部署才进入页面。当前 meta.last_updated 为 2026-09-14T08:54:45Z，主界面不展示该时间；它与部署时间、用户访问时间不同。

界面会依据运行时日期将已结束 upcoming 展示成历史，但不会修改 JSON。世界视图按数据 type 识别 upcoming，因此在自动归档部署前可能与卡片的时间状态不一致。日期计算没有响应式时钟，长期开着的页面跨 UTC 午夜不会保证自动更新倒计时。会议页 500ms、世界页 300ms 骨架是人工延迟，不代表网络数据加载。

数据规模是当前 13 个会议，而非文档原先声称的 15+；后续数量应继续以 JSON 为准。未来占位、未知城市、缺少 location_id、多个 DDL、隔年会议、已结束 upcoming 都是现有数据形态，后续 UI 应覆盖这些状态。
