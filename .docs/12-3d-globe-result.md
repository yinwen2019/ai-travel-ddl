# 世界视图：三维地球首版

> 2026-10-14。用户确认“科技感地球 + 卡通地标”方向，并授权实现、预览迭代与部署。此文与 05 中的世界视图规范覆盖 11 中此前的二维地图交付状态。

## 实现

- Vue 与数据流水线保持不变，移除 Leaflet，加入 Three.js 0.186.x 与 Globe.GL 2.46.x。
- 本地 GeoJSON 生成球面大陆点阵、国界和经纬网；不使用远程瓦片、纹理、模型或地图 API。
- 城市统计从既有 cityIndex 自动生成；保留五档累计场次与分类色语义，实心核心大小固定，外圈呼吸。
- 惯性旋转、空闲自转、动画暂停、双指缩放、缩放按钮、复位、城市选择、年表定位、页面全屏。
- 巴黎、悉尼、西雅图、新加坡使用原创程序几何模型。模型为城市意象，不代表会场；放大或选中时显示，可关闭。
- 城市详情在场景内展示。手机为详情留出镜头空间；全屏覆盖站点顶栏，恢复滚动并约束焦点。失败状态仍可退出全屏。
- 后台或离屏停止渲染；减少动态效果偏好关闭自动动画。手机初次加载降低大陆采样数和像素比。
- Montréal 与 Montreal 坐标键合并，年表保留原始城市文本。没有修改 data/ 或 scripts/。

## 验证

- JSON Schema、源代码 TypeScript、ESLint、Vite 生产构建通过。数据校验仍提示既有的当年 history 与未来缺少 DDL 警告。
- 临时 Node 断言共 19 项：重音城市聚合、累计场次五档、球面坐标方向与半径。72 个坐标城市；Montreal 包含重音拼写对应的会议，共 6 场。
- 正式构建预览检查 320、375、768、1024、1440px：页面没有横向溢出，控件在可见范围内；城市选择器包含 72 个城市。
- 桌面与手机全屏、城市详情、原始年表会议定位、暂停动画经过浏览器检查。
- 年表选择 CVPR 2027 Seattle 后焦点进入城市面板，关闭恢复原年表按钮。
- 临时移走 dist 中 GeoJSON：出现失败重试入口且年表保留。恢复资源后重试成功；源资源未改动。
- 独立审阅提出的全屏失败出口与年表焦点问题已修正，定向复核结论为 ship。Impeccable 引擎此前不可用，本轮未声称运行其自动检测器。

## 体积与边界

三维引擎分块约 1.95 MB，gzip 约 550 KB，仅进入世界视图时加载；会议与年份首页不需要下载该分块。构建对此给出大分块提醒。首版没有承诺帧率，未在实体低端手机或 Safari 上完成实测。

暂未加入历史路线飞线、用户自定义地点编辑或远程模型生成。新城市具有坐标即可自动展示普通会议点，专属地标按需补充。多洲会议城市在球面上无法同时全部可见，远景允许继续旋转浏览。

部署沿用仓库现有 GitHub Actions → GitHub Pages；base 为相对路径，Hash 路由保持不变。
