# 首页地球自转

2026-10-16，用户确认 Canvas 球面投影、12 秒一圈，保留背景地球现有尺寸、位置和冷蓝灰外观。对应 REQ-C19。

## 实现

- `HomeGlobe.vue` 保留原 SVG 作为首屏和失败回退，异步加载 D3 Geo 与精简地理数据，使用正投影绘制海洋、大陆、国界和经纬线；首页不加载 Three.js。
- 旋转按实际经过时间计算，每 12 秒一圈。绘制节流目标约 30fps，画布像素密度上限 2。只有地理投影改变，榜单文字和数字不跟随地球转动。
- 榜单标题右侧提供独立的地球暂停 / 继续按钮；与新增榜单轮播自己的控件分开。手动暂停、页面隐藏和地球离屏时取消动画帧，恢复时重新建立时间起点，不补算暂停时间。
- 减少动态效果偏好下显示原始固定方向，隐藏无效自转控制。主题切换重新读取既有 CSS 颜色。组件退出取消帧回调、监听器和两个观察器，异步加载完成时也检查组件是否已退出。
- `tools/build-home-geography.mjs` 从既有本地 GeoJSON 生成 `home-land.json`；242 个地理特征、1,632 个闭环、23,004 个坐标。简化或量化可能造成球面内外翻转的微小多边形保留原始坐标。会议与城市 JSON 没有修改。

## 验证与边界

- 类型检查、相关 ESLint、JSON 数据校验、构建和差异空白检查通过。构建仍提示既有世界三维引擎的较大分块；首页没有引用该引擎。
- 临时组件运行检查通过：半圈 / 整圈计时、暂停恢复不跳转、离屏 / 后台停止、减少动态效果、主题重绘与卸载清理。此部分为可控环境的生命周期验证，不代表真实低端设备性能测试。
- 几何检查通过：所有特征球面面积有效、闭环有效，12 个不同旋转朝向均可正确投影。
- 本地浏览器检查 1280px 桌面、375px 手机、320px 深色窄屏；Canvas 正常显示、暂停入口可操作、无页面横向溢出、无浏览器错误。暂停前后两次截图文件完全一致，继续播放后的两次截图不同，验证画面确实停止与恢复。运行目标为约 30fps，不承诺所有设备的固定帧率。
- 截图记录于工作区对应的 `home-spin-review` 目录。开发期间另一个任务同时扩展首页榜单与社区入口，本任务保留其改动并接入独立的地球控制插槽。
