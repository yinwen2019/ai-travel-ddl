# 15 — 城市视图交付记录

日期：2026-10-15。范围：新增城市目录、完善城市旅行详情，统一其他页面的城市文字入口。对应 REQ-A01、C09、C12、C14、C15、C18；产品与设计基线仍由 `01-requirements.md`、`05-ui-design-spec.md` 维护。

## 交付结果

- 新增 `#/cities` 第四个主导航入口与 `#/cities/:id` 详情；详情仍高亮城市视图，旧 `#/location/:id` 兼容重定向。保留会议首页、世界地图与年表；介绍型首页后续再规划。
- 当前数据只读聚合为 **72 座城市，其中 10 座有既有旅行指南**。10 座指南使用景点、季节、美食卡片，其余 62 座使用紧凑目的地列表；没有补写旅行资料、照片或会议数据。
- 搜索覆盖城市、国家、景点与美食，可组合大洲与仅看指南筛选；地址保存筛选状态，空结果和未知城市地址提供恢复入口。
- 详情展示景点、美食、季节、语言、货币、气候、旅行贴士、待参会与全部关联会议年份。无指南城市保留会议记录，各旅行栏目显示「待公布」。气候表保留原始温度数值与负号，降水独立展示，不足全年明确标注。
- 会议卡片、时间轴、世界年表和地图面板的城市标题统一新标签页打开详情。地图画布选中仍打开原页城市面板；年表另设明确的地图定位按钮。

## 与原基线的对照

| 原基线 | 当前结果与证据 |
|---|---|
| 三个主视图；地点百科无总览入口 | 顶栏新增城市视图，`CityViewPage.vue` 提供目录，`router.ts` 保留旧地址重定向 |
| 地点链接依赖 `location_id`；未匹配指南为普通文本 | `cityDirectory.ts` / `useCityDirectory.ts` 按城市与国家聚合，`CityLink.vue` 统一文字入口；不依赖坐标与外键 |
| 只有既有指南可查看旅行百科 | 全部实体会议目的地可打开详情；指南缺失时明确降级，会议关联仍可用 |
| 世界年表城市文字承担地图定位 | 城市文字打开详情，独立定位按钮保留地图探索；`WorldTable.vue` / `WorldCityPanel.vue` 对应两种入口 |
| 气候展示需防止少量月份暗示全年、负温度表达失真 | `ClimateCard.vue` 使用精确数值表与独立降水柱，标注收录月份，窄屏仅表格局部滚动 |

延续既有暖色设计、字体、品牌、主题变量与内容优先层级。目录三 / 二 / 单列响应式，详情桌面主栏与侧栏、手机单列；四项手机导航适配 320px。新增样式集中在 `cities.css`，主导航及 chip 选中小字复用已有 `--color-brand-dark`。
