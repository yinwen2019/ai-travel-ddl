# 13 — 世界地图底图与候选

> 2026-10-14 · 用户已确认并实现 A 默认、开关切换 B；C / D / E 保留为未实现候选。

## 已修正的近景问题

原镜头最低高度 0.45 且光点采用固定世界坐标大小，导致港澳深等相邻城市即使放大也互相遮挡。现最低高度为球体半径的 0.025，城市定位高度为 0.08；光点按相机空间深度换算为固定屏幕像素大小，保留累计场次五档。城市名改为固定字号的 HTML 标签，在视口内避让。桌面与手机近景均验证香港、澳门、深圳分别显示，未改动会议数据或坐标。

## 引擎能力与当前实现

现有 Three.js + Globe.GL 已支持球面图片、凹凸贴图、GeoJSON 面填充与按缩放加载的栅格瓦片，无须更换框架或地球引擎。网站当前使用本地连续矢量陆地（A），以及国界和经纬网。点阵填充已移除；B 地形方案经用户查看效果后于 2026-10-15 移除。

官方能力说明：[Globe.GL API](https://globe.gl/)。A 已接入，B 已试用后移除，以下 C / D / E 仍为调研候选。

| 编号 | 底图 | 视觉与适配建议 | 资源和近景边界 |
|---|---|---|---|
| A | 清爽矢量色块 | 连续陆地填色、细国界、纯色海洋；推荐默认，方便叠加会议点和卡通地标；可设计深浅两个配色 | 本地 GeoJSON 可实现；矢量边缘清晰，但地理细节取决于原始数据，近景应换更细海岸数据 |
| B | 柔和地形图 | Natural Earth I / II 风格，带山脉与地势纹理，更有旅行地图感 | 优化后的本地纹理可实现；单张纹理放大后清晰度有上限 |
| C | 真实蓝色地球 | NASA Blue Marble，自然海陆色，接近从太空观察地球 | 可使用优化后的本地纹理；属于合成影像，不是实时卫星画面；近景清晰度受纹理分辨率限制 |
| D | 城市夜景 | NASA Black Marble，夜间城市灯光，科技感强 | 可使用优化后的本地纹理；资料页包含 2016 年合成图，非实时；背景灯光可能与会议光点争抢注意力 |
| E | 精细地图瓦片 | 深色、浅色或彩色地图；随缩放加载更细海岸、道路和地名 | Globe.GL 有栅格瓦片接口；需自托管或外部地图服务。当前 REQ-C11 禁止运行时第三方瓦片服务，选择外部服务须先明确修改该约束；完整世界高缩放瓦片不宜直接全部放入静态项目 |

最初调研推荐 A 为默认、B 为可切换备选；当前按用户选择仅保留 A。如果用户更重视科技感，可选 D；如果更重视近景地理细节，可选 E。风格判断属于本项目的设计建议。

## 2026-10-15 加载与首帧修正

上一版在浏览器内解析 2,067,556 字节 GeoJSON，并为 1,620 个独立多边形生成球面网格，随后再绘制。加载占位在引擎完成异步图层更新前撤掉，容易先显示球面、再卡顿补上大陆。

- 使用 `npm run map:prepare` 离线生成连续矢量网格与边界，发布 673,444 字节的 `world-mesh.bin.gz`，保留原始 GeoJSON 作为制作源文件。实际海岸与三角面仍来自同一份 1:50m 数据，未通过减少地理细节提速。
- 陆地合并为一个 Mesh，不再临时生成 1,620 个多边形对象；边界共享顶点并禁用底图命中计算，城市光点交互照常。
- 地理资源与 3D 引擎并行请求。解压后的只读数组在当前页面会话内缓存，离开世界页再返回时复用；GPU 场景仍正常销毁。
- 加载期间隐藏实际画布，只显示轻量加载指示。城市对象挂载、初始视角、着色器准备和完整渲染帧就绪后，才撤掉占位；不添加固定等待时长。减少动态效果偏好下停止加载指示动画。
- 首次进场已有选中城市时直接使用目标视角，避免占位消失后再飞行；原有缩放逻辑保持。

本机 Node 26 的局部 CPU 对比：原网格生成约 1,641 ms，新网格解码与校验 12 次测试中位数约 5.45 ms、最大约 6.94 ms。此数字仅比较地理数据处理，**不代表整页加载时间**，下载、WebGL 初始化和着色器准备仍需要时间。格式损坏、截断与量化半径误差检查通过。

## 2026-10-15 图例、地标与缩放细节

- 图例改为持续展开，移除开关及对应隐藏状态；手机底部紧凑排列，不与工具栏和城市详情重叠。
- 五档核心半径从原来的 3.6–6.8px 调整为 3.5 / 5 / 7 / 9.5 / 12.5px；图例读取同一函数，保证在全球和近景的大小区别保持一致，仍采用固定屏幕像素换算。
- 地标先归一化包围盒，再按屏幕方向放在城市光点左侧，标签放在右侧。模型使用独立的约 30×32px 尺寸预算与轻微透视，不继承统计点的视觉大小。为模型厚度留出深度，避免球面截断建筑；标签避让包含模型范围。
- 缩放按钮目标高度按 0.55 / 其倒数累计，使用独立逐帧指数插值平滑追踪。旧引擎转场在新请求到达时会先结束至旧目标，原来的连续点击容易跳动；新按钮缩放不再叠加该转场。滚轮/拖动、城市定位、离屏与销毁时取消按钮动画。暂停自转仍可平滑缩放，减少动态效果时跳过空间过渡。
- 已检查巴黎、悉尼桌面与手机布局、常驻图例、深浅主题、连续按钮缩放；36 组投影检查覆盖四种地标、三种镜头高度和三种观察偏角，模型均在城市左侧；60/120Hz 插值的连续目标和反向收敛检查通过。
