# 05 — UI 设计规范

> 2026-10-14 · 地图工具；2026-10-15 扩展城市视图与蓝灰首页；2026-10-16 扩展四榜、Rankings 与本机互动预览。本文是当前 UI 实现基线，跨页面视觉规范见根目录 DESIGN.md。功能编号仍见 01；重构前的状态保留在 10-ui-audit.md，不代表当前缺陷。

## 定位与品牌

面向研究者的会议、年份、世界地图与城市旅行信息工具。默认首页连接四个功能视图及排行榜，主导航为 Home、World、Conference、Year、City、Rankings。2026-10-15 经用户确认采用冷蓝灰方向；视觉清晰、克制，带有地图与旅行意味，统计须标明真实来源与范围。

用户选定品牌为“折线地图”：单色几何地图加目的地点，顶栏与 favicon 同源形态；保留 ConfTrip 名称。品牌色、分类色和 DDL 状态色分别承担不同语义。

- 状态指示色沿用灰 / 靛蓝 / 红 / 橙 / 绿；正文使用更深的 `--color-*-text`，保证可读性，不直接用亮色小字。
- 分类点沿用 CV 红、NLP 紫、ML 绿、AI 蓝、DM 橙；chip 与 badge 采用中性底和正常文字，并提供分类名称，避免只靠颜色辨识。
- 字体栈：Avenir Next、Segoe UI、PingFang SC、Microsoft YaHei、sans-serif；无外部字体请求。
- 页面标题 24–28px；会议标题 16px；卡片信息 14px；辅助信息 12px；连续介绍正文 16px。日期启用 tabular-nums。
- 间距 4/8/12/16/24/32px；卡片 12px 圆角与 16px 内边距；控件 8px 圆角。
- 普通卡片不做悬浮上移，不整体降透明；历史通过中性背景和“已结束”文字区分。
- 链接使用品牌蓝与下划线反馈，取消渐变文字。普通控件与主要触控入口至少 44px；地图光点保留大小编码，并提供年表按钮等价操作。
- 主导航与筛选 chip 的选中文字使用已有 `--color-brand-dark`，浅品牌底使用 `--color-brand-light`，避免普通链接色用于选中小字时对比不足。

## 全站布局

会议和世界页最大宽度 1440px，年份与城市目录页 1280px，详情页 1120px。桌面水平内边距 24px，手机 16px。

共享 AppHeader 仅包含标识、主导航和主题按钮。手机第一行品牌与主题，六项导航位于下方，<768px 使用 3 列 × 2 行，每项至少 44px 高，支持 320px 窄屏；该补充规则位于 `rankings.css`。会议详情高亮 Conference，城市详情高亮 City，排行榜高亮 Rankings。只有共享顶栏吸顶；搜索、筛选和年份工具栏归各视图所有。

页面预留稳定的滚动条空间，筛选结果变少时不会因滚动条消失造成工具栏和内容横向位移。

页脚展示品牌、来源提醒与数据 `meta.last_updated` 的 UTC 日期。该时间是会议数据更新时间，不代表实时请求或部署时间。

## 首页

`#/` 为 HomePage；原会议维度页移至 `#/conference`。首页最大宽度 1280px，桌面内边距 48px，≤1100px 为 32px，<640px 为 20px。

- 桌面双栏：左侧标题「从一场会议，出发看世界。」、两行简介、World 主按钮、Conference 次入口与真实覆盖数量；右侧正投影自转地球叠城市历史举办榜。地球采用本地精简地理数据与 Canvas，静态 SVG 为首屏及失败回退；桌面宽 540px，不承担地图交互、不加载三维引擎。主标题使用系统字体、650 字重与紧凑字距，桌面 clamp(40px,4.3vw,56px)，手机 clamp(34px,9.5vw,46px)。
- 右侧为四榜轮播：城市举办、会议热度、城市热度、城市期待。按用户批注，榜单行及空状态内容区使用完全透明背景，不增加渐变或半透明底色，保留文字、国家色条和分隔线。举办榜共用城市目录规范化结果，只统计 `type=history` 的实体届次，排除线上与未来届次；取前八城市，保留真实并列名次。显示城市、国家、比例条、次数、国家图例与统计范围说明，数据为空时显示提示。城市行新标签页打开详情并使用 `noopener`。“榜单详情”同页进入 Rankings 并保留所选榜单。
- 按用户批注移除榜单顶部四项导航；44×44px 左右箭头悬浮在榜单内容两侧并偏移避让列表，不显示底部控制行、页码或播放 / 暂停按钮。榜单仅手动切换，无定时自动播放。切换只使用淡入 220ms、退场 120ms，不推移地球或简介，面板保持最小高度以降低版面跳动；减少动态效果直接切换。
- 热度榜显示“尚未开启”，当前浏览与点击不采集；后续按用户确认的显式主动对象点击全部累计，排除自动状态变化，不设停留门槛、日去重或统计周期。城市期待表达希望该城承办会议，本机每次可重复累积 `+1`，不取消，并注明本机范围。没有数据时提供解释与探索入口，不能以举办记录或虚构数字填充热度。
- 简介下方增加爱心“点个赞”、本机累计数、GitHub 与小红书图标。控件至少 44px；局部爱心色仅承担支持反馈，不替代品牌、DDL 或分类颜色。爱心点击缩放 280ms，`+1` 上浮淡出 650ms；快速连点最多保留五个反馈粒子。减少动态效果取消缩放与位移，保留短文字确认和计数；用户已确认连续加一，不设每日产品上限。小红书默认采用用户提供的 `https://xhslink.cn/o/5YIh8OKvkvn`，公共环境配置可覆盖，缺失或无效时回退默认链接。
- 下方四个功能入口采用开放排版与细分隔线，无独立卡片框；桌面一排四项，<640px 为 2×2。手机主区按介绍、榜单、入口顺序排列。主导航、主次入口、全部城市与四个功能入口同页切换。
- 简介入场 760ms，地球入场 1100ms，均使用 cubic-bezier(0.16,1,0.3,1)，只运行一次；控件反馈 160ms。2026-10-16 经用户确认增加 40 秒一圈的匀速球面自转，绘制目标约 30fps、像素密度上限 2；只有背景地球移动，榜单固定。按用户后续批注移除地球暂停按钮，离屏与后台时停止循环，恢复不跳转；减少动态效果偏好下不运行入场或自转，固定初始方向。无运行时 GSAP、远程地图或字体依赖。
- 首页方向与证据边界见 `.impeccable/surface-briefs/home.md`；既有首页交付见 `16-homepage-result.md`，本轮排行榜与互动记录见 `20-rankings-result.md`，用户已确认的统计口径与免费架构方案见 `19-rankings-analytics-plan.md`，全站采集仍未接入。

## 排行榜

`#/rankings` 最大宽度 1280px，沿用系统字体、冷蓝灰颜色与开放式细分隔列表，不引入图片、字体或动效运行时依赖。

- 顶部四个榜单选择入口，桌面四列、<768px 两列；当前项使用品牌浅底与深品牌文字，按钮说明各榜含义。榜单选择保存在 `board` 参数，未知值回退城市举办榜。
- 桌面左侧搜索与完整列表，右侧 224px 统计口径栏（中等宽度 200px）；手机依次为榜单选择、搜索与结果数、口径摘要、列表。行内信息随宽度改为多行，城市名、国家、关联会议、数值仍可读，避免整页横向滚动。
- 举办榜展示完整历史城市排名、会议及年份范围，搜索匹配城市、国家和关联会议；搜索同步 `q`，保留原名次，提供清除与空结果恢复入口。已有举办榜数据和所有会议静态 JSON 均不写入。
- 期待榜展示希望城市承办会议的本机累计票数，独立 44px 按钮每次 `+1`，同城可反复点击，不是取消式选择；零票项显示“—”名次，不能把候选包装成排名。保存失败时提示仅本次浏览。
- 热度榜不显示假名次或数值，明确标注尚未开启并提供 Conference、City 入口。用户已确认累计主动点击及 Cloudflare 免费方案，本轮只做 UI 与方案，未创建服务或开启采集。
- 城市详情新标签页打开，期待按钮不嵌套在链接中；点击城市不同时给期待加票，期待点击只改变期待累计。榜单切换、投票反馈与辅助播报保留键盘等价操作，减少动态效果取消控件缩放与过渡。

## 会议视图

- 顶部搜索 + 五分类复选分组；桌面五组、平板两组、手机展开后一组一行。无选择展示全部，选择与搜索取交集。
- 内容、结果计数、空状态均使用交集。筛选区下方只保留一条紧凑结果状态栏，统一展示「显示 N 个会议」及「清空选择」，不重复展示已选数量。清空按钮始终占位，无选择时禁用；复选分组和状态栏在勾选前后保持位置与高度稳定。手机折叠筛选时仍显示结果状态栏，筛选按钮不附加动态计数。空结果可通过该栏清空选择或通过空状态清除搜索。
- 每会议一行，行与行之间用细分隔线区分。桌面左侧展示会议标识，右侧为独立年份轮播；手机会议标识在上方。使用全站冷蓝灰配色与既有系统字体，不新增装饰背景。
- 会议行采用紧凑密度：上下留白 16px、轮播上下留白 8px，行内卡片内边距 12px、信息间距 4px。2026-10-16 按用户反馈进一步收紧：卡片标题保留「会议名 + 年份」，与当前状态同排，分类与详情入口由行头承担；手机行头详情与会议名同排。卡片宽度 ≥420px 时城市、会期、官网同排，更窄时城市和会期在左、官网在右。当前状态 13px，城市 14px、辅助信息 12px；箭头与官网入口保留 44px 触控面积。轮播卡片保持等高，切换年份不改变行高；年份视图沿用原有完整卡片布局。
- 同年会期用月日范围，年份由卡片标题提供；跨年保留完整日期，完整会期保留 title 与可访问文本。经用户选择方案 1，紧凑时间节点采用等距里程碑：细线串联「摘要 / 正文 / 开会」，日期已过的节点变灰并打勾，下一个节点用 DDL 状态色突出，每个节点下统一展示实际日期（YYYY.MM.DD），倒计时只保留在卡片上方。打勾表示日期已过，不表示用户已经投稿；节点位置表示阶段顺序，不表示真实时间比例。实际日期缺失时跳过节点，单节点靠左显示，不补造连线或进度；完整日期、状态保留可访问名称与 title。保持两行紧凑高度，不重复无节点的「日期待公布」，Year 保留原时间节点样式。
- 源数据会议顺序保留；各会议所有年份从左到右降序排列，较新届次在左、往届历史在右；默认聚焦最近一届未结束会议，无未结束会议时聚焦最新历史届。
- 轮播中间完整展示一张卡片，左右相邻卡片缩小并弱化，仅作为预览。当前卡片用品牌色细边框强调；轮播两侧使用 44px 圆形悬浮箭头，边界按钮禁用。下方展示当前年份及届次位置；不自动播放。
- 使用原生横向滚动与居中 scroll snap；左箭头/左方向键切换较新一届，右箭头/右方向键切换往届，Home/End 分别定位最新/最早一届。支持触屏滑动。隐藏卡片不进入焦点顺序，尺寸变化后保持当前年份居中；减少动态效果偏好下直接切换。
- 行头包含缩写、全称及分类；卡片展示会议年份、当前状态、地点、会期、进度节点和官网。历史卡片不再折叠，直接通过年份轮播浏览。
- 标题与“历届详情”进入已有详情路由；可识别的实体城市通过统一城市链接在新标签页打开 `#/cities/:id`，不以 location_id 是否存在为条件；官网优先该届 url，再回退会议 website。

## 世界视图

上地图、下年表。五分类筛选位于地图下方、年表标题后与表格前，作为年表工具栏；仅筛选年表，地图保持全量，工具栏下明确说明范围。632px 宽度下一行显示五项，更窄时自然换行，不将末项拉伸成整行；世界页不显示无效的搜索框。

- 经用户确认使用 Three.js + Globe.GL，将地图区域替换为科技感三维地球；场景、外围页面与共享品牌统一采用全站冷蓝灰方向。
- 地图跟随站点浅色/深色主题，与全站冷蓝灰方向对齐：日间冷雾背景 #F1F5F6、雾蓝海洋 #DCE8EB、蓝灰陆地 #9EBBC4、冷白浮层 #FCFEFE、地图蓝强调 #295B73；夜间深墨蓝背景 #111E26、深海蓝海洋 #1D3542、低饱和蓝灰陆地 #537985、深蓝浮层 #172832、浅蓝强调 #A1C8D8。三维材质定义在 `src/utils/globeTheme.ts`，浮层直接复用全站文字、表面、边框与品牌色变量；选中光环和定位针采用品牌蓝系。日间隐藏星空并收弱大气光，夜间保留稀疏低亮度星点。
- 本地 Natural Earth 1:50m GeoJSON 生成连续陆地、国界和经纬网；不请求外部地图、纹理或模型服务。3D 引擎在世界路由中异步加载。
- 桌面高度 clamp(530px,74svh,820px)，手机 560px；页面全屏覆盖站点顶栏，保留城市面板、控件与图例，退出后恢复滚动和焦点。
- 支持惯性拖动、Mac 触控板双指捏合、鼠标滚轮缩放、缩放按钮和复位；指针位于地图画布时滚轮控制地图缩放，地图外正常滚动页面。空闲缓慢自转，交互、悬停、选中城市或面板阅读时停止自转。
- 缩放按钮每次将镜头高度乘以 0.55 / 其倒数，连续点击累计目标，以逐帧指数插值衔接，避免旧动画先跳到终点。暂停自转不关闭按钮过渡；系统减少动态效果时直接切换，初次定位不做飞行动画。
- 保留累计场次五档与分类色语义，历史光点日间深灰绿、夜间浅灰绿，与图例一致。核心半径按屏幕像素维持五档大小，不随镜头接近而膨胀，仅外围光晕轻缓呼吸；暂停按钮同时停止自转和呼吸。

## 城市视图

`#/cities` 是可搜索的目的地目录，沿用全站冷蓝灰配色、系统字体、细边框与克制层级。页头说明城市与旅行指南覆盖数量，并提供「在世界地图探索」入口；统计取实际数据，不作为装饰性指标。

- 工具栏包含城市、国家、景点或美食搜索，大洲筛选，以及「仅看有旅行指南的城市」。筛选取交集，结果数量与重置同列；空结果提供浏览全部城市入口。`q`、`continent`、`guide=1` 保存到地址，刷新及浏览器返回恢复状态。
- 有指南的城市使用内容卡片，展示城市与国家、介绍、代表景点、适宜季节、美食及会议届数；不补造照片。卡片为 12px 圆角、20px 内边距，城市标题 20px、正文 14px、辅助文字 12px。悬停或键盘聚焦只强调边框与焦点，不悬浮上移。
- 指南卡片及其余目的地列表在 ≥1024px 为三列、640–1023px 两列、<640px 单列。没有指南的目的地采用紧凑分隔列表，保留国家、会议届数与详情入口，不用大批空卡片重复「待公布」。
- 城市卡片和列表入口均在新标签页打开详情，并在可见文案与链接名称中说明；源数据缺少坐标、location_id 或旅行指南时，仍保留城市入口。

`#/cities/:id` 展示城市、国家与大洲、介绍，以及季节 / 语言 / 货币摘要。桌面主体为景点、美食、气候，侧栏为旅行贴士、待参会和全部关联会议年份；<768px 依次排为单列。详情页提供城市视图面包屑。旅行资料缺失时对应栏目明确显示「待公布」，不影响关联会议；未知城市地址提供恢复入口。旧 `#/location/:id` 兼容重定向至同 ID 详情。

## 详情、反馈与可访问性

会议时间轴同步语义颜色、字号、间距和控件，城市地点链接遵循统一的新标签页规则。城市气候使用带行列标题的表格，均温保留原始数值及负号，降水在独立一行显示柱形与毫米数值；不共用温度、降水的图形比例。按实际月份数量决定最小宽度，月份较多时保留独立可聚焦的横向滚动区域；不足 12 个月明确标注覆盖范围，不插补未收录月份。

搜索保持 200ms 防抖，外部清除同步输入框；所有图标按钮有名称，所有控件有清晰焦点，选中/展开使用相应 ARIA 状态。减少动态效果偏好下跳过地图飞行与平滑滚动。

## 已知边界

本轮不统一地图 raw type 与卡片运行日期归档，不增加跨 UTC 午夜响应时钟，不做 IANA 精确截稿时区换算，不补“现在 / 结束”等完整进度流程；这些仍属于既有需求与实现的待办差异。桌面顶部筛选是本次用户确认的 UI 方案，不按旧文档恢复左侧栏。
