# 05 — UI 设计规范

> 2026-10-14 · 暖色地图工具。本文是当前 UI 实现基线。功能编号仍见 01；重构前的状态保留在 10-ui-audit.md，不代表当前缺陷。

## 定位与品牌

面向研究者的会议、年份和世界地图信息工具。保留三视图与会议首页，不添加宣传大图、统计装饰或无关交互。视觉气质温和、清晰、略有旅行趣味。

用户选定品牌为“折线地图”：单色几何地图加目的地点，顶栏与 favicon 同源形态；保留 AI Travel DDL 名称。品牌色、分类色和 DDL 状态色分别承担不同语义。

## 色彩与字体

| 用途 | Light | Dark |
|---|---|---|
| 页面背景 | #F5F3EE | #242321 |
| 卡片 / 浮层 | #FFFEFB | #2E2C29 |
| 主文字 | #2D2A26 | #F2EEE7 |
| 次文字 | #6B645C | #BDB5AB |
| 边框 | #DED8CF | #514B44 |
| 品牌 / 链接 | #A64B35 | #E8A58D |

定义位于 main.css 的 `--color-*` 变量。Tailwind 的 brand/canvas/surface/subtle/primary/secondary/line 引用相同变量；地图通过 `--world-*` 适配主题。主题跟随系统初始偏好，手动选择持久化。

- 状态指示色沿用灰 / 靛蓝 / 红 / 橙 / 绿；正文使用更深的 `--color-*-text`，保证可读性，不直接用亮色小字。
- 分类点沿用 CV 红、NLP 紫、ML 绿、AI 蓝、DM 橙；chip 与 badge 采用中性底和正常文字，并提供分类名称，避免只靠颜色辨识。
- 字体栈：Avenir Next、Segoe UI、PingFang SC、Microsoft YaHei、sans-serif；无外部字体请求。
- 页面标题 24–28px；会议标题 16px；卡片信息 14px；辅助信息 12px；连续介绍正文 16px。日期启用 tabular-nums。
- 间距 4/8/12/16/24/32px；卡片 12px 圆角与 16px 内边距；控件 8px 圆角。
- 普通卡片不做悬浮上移，不整体降透明；历史通过中性背景和“已结束”文字区分。
- 链接使用陶土色与下划线反馈，取消渐变文字。普通控件与主要触控入口至少 44px；地图光点保留大小编码，并提供年表按钮等价操作。

## 全站布局

会议和世界页最大宽度 1440px，年份页 1280px，详情页 1120px。桌面水平内边距 24px，手机 16px。

共享 AppHeader 仅包含标识、主导航和主题按钮。手机第一行品牌与主题、第二行三等分导航。只有共享顶栏吸顶；搜索、筛选和年份工具栏归各视图所有。

页脚展示品牌、来源提醒与数据 `meta.last_updated` 的 UTC 日期。该时间是会议数据更新时间，不代表实时请求或部署时间。

## 会议视图

- 顶部搜索 + 五分类复选分组；桌面五组、平板两组、手机展开后一组一行。无选择展示全部，选择与搜索取交集。
- 内容、结果计数、空状态均使用交集；空状态可分别清除搜索或选择。
- 每会议一列；桌面在 280–360px 间分配，最多按四列计算，多会议在局部容器横向滚动。手机一列为容器宽度减 24px，提示可继续横向浏览。
- 源数据会议顺序保留；有效 upcoming 按年份降序，随后历史默认两届，可展开。
- 列头包含缩写、全称及分类；卡片展示会议年份、当前状态、地点、会期、进度节点和官网。
- 标题与“历届详情”进入已有详情路由；有 location_id 的地点在新标签页打开百科；官网优先该届 url，再回退会议 website。

## 年份视图

年份 Tabs 从数据降序生成，默认浏览器当前年份。现有排序原则不变。网格通过 CSS 断点实现，避免 JS 响应式判断函数误用。

| 宽度 | 列数 |
|---|---|
| <768px | 1 |
| 768–1023px | 2 |
| 1024–1279px | 3 |
| ≥1280px | 4 |

共用 ConferenceCard。ProgressBar 保留摘要、正文、开会三个现有节点；每类 DDL 取最早未截止项，全过期时取最近已过日期，节点按日期排序。未知跳过，全部缺失显示“日期待公布”；采用等分空间，无固定连接线宽度。

无有效投稿 DDL 的非历史、非开会状态展示“投稿日期待公布”，不默认绿色。待开会和正在开会保留地点信息。仍按 UTC 日期计算，不承诺精确到小时。

## 世界视图

上地图、下年表。分类只筛选年表，地图保持全量，页面明确说明范围；世界页不显示无效的搜索框。

- 经用户确认使用 Three.js + Globe.GL，将地图区域替换为科技感三维地球；其他视图与品牌沿用暖色设计。
- 场景背景 #050E19，默认海洋 #102C43，连续陆地 #54818A，大气光 #58BDCA，面板 #0C2031，正文 #E7F1F3，辅助文字 #A3BDCA。固定深色场景，周边页面保留主题切换。
- 本地 Natural Earth 1:50m GeoJSON 生成连续陆地、国界和经纬网；不请求外部地图、纹理或模型服务。3D 引擎在世界路由中异步加载。
- 桌面高度 clamp(530px,74svh,820px)，手机 560px；页面全屏覆盖站点顶栏，保留城市面板、控件与图例，退出后恢复滚动和焦点。
- 支持惯性拖动、双指缩放、缩放按钮和复位；滚轮保留页面滚动。空闲缓慢自转，交互、悬停、选中城市或面板阅读时停止自转。
- 保留累计场次五档与分类色语义，历史光点灰蓝。核心半径按屏幕像素维持五档大小，不随镜头接近而膨胀，仅外围光晕轻缓呼吸；暂停按钮同时停止自转和呼吸。
- 允许从全球放大至相邻城市可区分的区域尺度，镜头最低高度为球体半径的 0.025，城市定位默认 0.08；近景已验证香港、澳门、深圳可分别点选。城市名使用固定 12px 标签，按当前可见区域和屏幕空间避让，桌面最多 14 个、手机最多 8 个，优先保留选中城市。
- 巴黎、悉尼、西雅图、新加坡使用原创几何地标；接近区域或选中时出现。地标为城市意象，非会议场馆；没有地标的城市仍显示会议点。
- 顶部城市选择器提供所有可定位城市的键盘入口。Hover 预览城市，点击打开城市面板并转向城市；手机镜头上移给详情留白。关闭面板恢复来源焦点，Escape 逐层关闭。
- 年表固定年份列，局部横向滚动；hover/focus 高亮城市，点击城市定位，点击会议列头按举办城市范围调整视角。
- 加载显示真实占位，失败可重试并保留年表；减少动态效果偏好下停止自动动画，标签页后台和场景离屏时暂停渲染。手机降低初始粒子量与像素比。
- 城市坐标键去除重音差异，例如 Montréal 与 Montreal 聚合为同一城市；年表继续显示原始名称，不修改会议 JSON。

世界地图仅保留「清爽矢量色块」底图。2026-10-15 经用户查看效果后，移除「柔和地形」开关、纹理资源及加载逻辑；保留连续陆地、国界、经纬网、城市光点、地标与年表联动，以及完整首帧就绪后再显示地图的加载优化。底图与资源说明见 `13-world-map-layers.md`。

## 详情、反馈与可访问性

会议时间轴与城市百科保留内容顺序，同步语义颜色、字号、间距和控件。气候图按实际月份数量决定最小宽度，月份较多时保留独立可聚焦的横向滚动区域；不足 12 个月明确标注覆盖范围。

搜索保持 200ms 防抖，外部清除同步输入框；所有图标按钮有名称，所有控件有清晰焦点，选中/展开使用相应 ARIA 状态。减少动态效果偏好下跳过地图飞行与平滑滚动。

## 已知边界

本轮不统一地图 raw type 与卡片运行日期归档，不增加跨 UTC 午夜响应时钟，不做 IANA 精确截稿时区换算，不补“现在 / 结束”等完整进度流程；这些仍属于既有需求与实现的待办差异。桌面顶部筛选是本次用户确认的 UI 方案，不按旧文档恢复左侧栏。
