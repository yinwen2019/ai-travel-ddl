## 从投稿计划，到下一次出发

ConfTrip 面向 AI 研究者和学生，把会议日期、历年举办地与城市旅行资料放在一起。准备下一篇论文时，也可以提前认识下一座学术城市。

- **安排研究日程** — 在[会议视图](https://aitravel.gonsun.com/#/conference)追踪关注的会议，在[年份视图](https://aitravel.gonsun.com/#/year)查看一年的投稿与会期。
- **探索参会目的地** — 旋转[世界地图](https://aitravel.gonsun.com/#/world)，或从[城市目录](https://aitravel.gonsun.com/#/cities)了解景点、季节、美食与关联会议。
- **发现大家的关注** — 在[排行榜](https://aitravel.gonsun.com/#/rankings)查看历史举办记录、会议热度与城市热度。
- **表达下一站期待** — 为希望承办会议的城市[投一票](https://aitravel.gonsun.com/#/rankings?board=city-wishlist)，也可以在首页点个赞，给项目一点鼓励。

## 四种榜单，看见关注与期待

首页左右箭头可以切换四类榜单，顶部 **Rankings** 进入完整列表。榜单支持搜索，同数并列，筛选后保留原名次。

| 榜单                                                                       | 排名依据                           |
| :------------------------------------------------------------------------- | :--------------------------------- |
| [城市举办榜](https://aitravel.gonsun.com/#/rankings?board=hosting)         | 已收录的历史线下会议届数           |
| [会议热度榜](https://aitravel.gonsun.com/#/rankings?board=conference-heat) | 会议的主动点击次数，跨年份合并     |
| [城市热度榜](https://aitravel.gonsun.com/#/rankings?board=city-heat)       | 城市的主动点击次数                 |
| [城市期待榜](https://aitravel.gonsun.com/#/rankings?board=city-wishlist)   | 希望这座城市承办未来会议的累计票数 |

**下一场会议，你希望在哪里参会？** 在城市期待榜中搜索一座已收录的城市，点击爱心，每次增加一票。投票已接入全站累计，支持重复投票，功能与体验仍在完善。

首页的「点个赞」同样支持连续点击，并有 `+1` 反馈。项目点赞与城市投票分别累计。

<details>
<summary>了解榜单统计口径</summary>

- 举办榜只统计本站收录的历史线下届次，不计线上会议与未来届次。
- 热度只计主动点击；刷新、悬停、筛选、切年和切换榜单不增加次数。
- 点击和投票可以重复累计，数值代表互动次数，不能当作独立用户人数；零次点击或零票的对象暂不排名。

</details>

## 收录会议

目前收录 13 个 AI 会议，涵盖历年举办信息与已公布的未来届次安排。

| 领域            | 会议                  |
| :-------------- | :-------------------- |
| 计算机视觉      | CVPR · ICCV · ECCV    |
| 自然语言处理    | ACL · EMNLP · NAACL   |
| 机器学习        | NeurIPS · ICML · ICLR |
| AI 综合与多媒体 | AAAI · IJCAI · ACM MM |
| 数据挖掘        | KDD                   |

会议数据由静态 JSON 管理，定时运行 AI 辅助检索与校验，有变更时创建更新 PR，审核合并后发布。日期和时区请以会议官网为准，未确认的信息显示「待公布」。

旅行指南目前覆盖部分城市。README 提供中英文版本，网站界面以中文为主。

## 本地运行

使用 Node.js 24 与 npm：

```bash
git clone https://github.com/yinwen2019/conftrip.git
cd conftrip
npm ci
npm run dev
```

打开终端显示的地址，默认为 `http://localhost:5173`。前端运行不需要 AI 服务密钥。

<details>
<summary><strong>开发与数据维护</strong></summary>

**技术栈**

Vue 3、TypeScript、Vite、Tailwind CSS、Vue Router、Three.js / Globe.GL 与 D3 Geo。前端由 GitHub Pages 托管，全站互动使用独立的 Cloudflare Worker + D1。

**项目结构**

```text
data/                会议资料、城市指南与 Schema
src/                 页面、组件与只读数据聚合
scripts/             数据校验与 AI 辅助更新
services/analytics/  独立互动统计服务
.docs/               需求与开发文档
```

**提交前检查**

```bash
npm run validate
npm run type-check
npm run build
```

修改数据时，请附上官方来源并核对日期与时区。开发约定见 [AGENTS.md](AGENTS.md)，数据格式见 [Schema 说明](.docs/04-data-schema.md)；AI 更新脚本需要 Python 3.11+ 及服务配置，参阅 [更新流程](.docs/08-ai-update-pipeline.md) 和 [.env.example](.env.example)。

**本地互动服务**

未配置统计 API 时，点赞和城市期待仅保存在当前浏览器，热度榜显示未开启。本机累计不会自动上传，开发模式也不会向正式统计服务提交。

如需联调，使用独立的本地测试数据库：

```bash
npm run analytics:db:local
npm run analytics:dev
# 在另一终端启动前端
VITE_ANALYTICS_API_URL=http://127.0.0.1:8788 npm run dev
```

详见[统计服务说明](services/analytics/README.md)与[接入文档](.docs/21-analytics-service-result.md)。

</details>
